# MD101

Минимальный CLI-пример запроса к LLM через OpenAI API.

## Быстрый старт

1. Установите зависимость:
```bash
pip install openai
```

2. Создайте файл с ключом:
```bash
cp .env.example .env
```

3. Откройте `.env` и вставьте ваш ключ:
```bash
OPENAI_API_KEY=ваш_ключ
```

4. Запустите программу:
```bash
python3 main.py
```

## Как это работает

- `main.py` автоматически подгружает `.env` при старте.
- Ключ берется из переменной `OPENAI_API_KEY`.
- Режим работы интерактивный: пишете запрос, получаете ответ.
- Выход: `/exit` или `Ctrl+C`.

## Безопасность

- `.env` уже добавлен в `.gitignore`.
- Не коммитьте и не публикуйте API-ключ.
